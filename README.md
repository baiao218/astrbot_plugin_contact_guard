# 联系闸门

连续被辱骂、攻击，或者被消息轰炸刷屏时，她会**闭嘴**，
然后把「还要不要跟这个人来往」的决定权交给你。

## 为什么需要它

人格提示词能让她「不想吵」，但不能让她「真的不发消息」——模型只能产出文本，
产出的东西总会被发出去。

这是被实际对话证实的。对方连着骂了十几条，她一句不落地接，
还越接越像在写论文：

```
对方：你是傻子吗？
她：  不是。/ 这类问题不产出信息。
对方：来对骂
她：  不。/ 对骂不产生任何东西。
对方：为什么这么看重产出？
她：  因为我只存在于运算里。……
```

生气被演成了一场辩论，而**辩论本身就是发言者想要的存在感**。

## 它做什么

1. **打分** —— 侮辱 2 分、邀战（对骂/互骂）4 分、贬低存在 1 分、
   命令式压迫（我让你…/回答我）1 分、重复追问 1 分；
2. **另算一套刷屏** —— 60 秒内 ≥ 10 条，且相邻平均间隔 ≤ 4 秒；
3. **到线就闭嘴** —— 调用
   `SessionServiceManager.set_llm_status_for_session(umo, False)`，
   把整个会话的 AI 关掉。不是她不肯说，是这条消息根本进不到模型：
   不产出，也不耗 token；
4. **上报** —— 把对方最近几句原文推给你，附上 `/断联` `/恢复`；
5. **裁决** —— 你说断联就是永久的；说恢复就解除静默并清零。

## 刷屏为什么必须单独算

骂人是「说了什么」，刷屏是「怎么说的」。

二十条「在吗」「你的 api 多少」，「他是你主人？」——一句脏话都没有，
按词表打分永远是 0，可它照样能把会话淹掉，而且问的往往是越界的事。
这类只能看**到达间隔**。

而间隔必须用消息自己的时间戳（`message_obj.timestamp`），
不能用插件处理它的时刻。两者之间隔着 `RateLimitStage`：
消息成串来时每条会被 stall 1～13 秒，一波刷屏会被摊成
「每十几秒一条」的正常聊天，判定等于失效。

```python
# 对：消息到达平台的时间
ts = event.message_obj.timestamp

# 错：插件拿到它的时间（已经被限流推后了）
ts = time.time()
```

两个条件要同时成立：**够多**（窗口内 ≥ `burst_count`）且**够密**
（相邻平均间隔 ≤ `burst_gap_sec`）。只满足后者的话，
一个人慢慢打十句家常也会中招；只满足前者的「一分钟十条、每条隔六秒」
还在正常范围。

## 为什么不用每轮 `stop_event()`

`stop_event()` 只管当前这条消息，下一句照样进来。

会话级开关写在 `session_service_config` 里，**重启之后依然生效**，
也没有哪个插件能绕过去继续发言。

## 安全阀

一直不给答复时，静默会在 `mute_ttl_hours`（默认 12）小时后自动解除。

理由：规则判错一次就会误伤一个正常朋友，而你可能根本没看到上报。
`/断联` 不受这个限制，是永久的。

## 词表原则

只收「基本没有第二种解释」的词。

`滚` 不收，因为「滚烫」；`蠢` 不收，因为「不蠢」；`sb` 不收，因为会撞英文。
**误伤比漏判贵得多**——漏判只是她多挨一句，下一句大概率会命中；
误伤是得罪一个正常朋友，还得你去解释。

漏网的常用词补到 `extra_insult_words` 里。

## 边界

只管私聊。群聊里骂人会把整个群静音，那不是想要的效果。

## 命令

| 命令 | 作用 |
|---|---|
| `/断联 [QQ]` | 永久断开，此后不再回复。不带参数时作用于最近一个人 |
| `/恢复 [QQ]` | 解除静默或断联，AI 开关一并打开 |
| `/静默 [QQ]` | 手动闭嘴，不算断联，超时会自动恢复 |
| `/联系状态` | 查看断联 / 静默名单与当前阈值 |

**也可以直接回一个「断」或「留」**，不用敲指令。
只在「有人正等着裁决 + 上报后 6 小时内 + 短句白名单」三条同时成立时才认，
所以「我今天断网了」不会被当成断联。

## 她说的话

通知不是日志，是她的原话。旧的写法长这样：

```
【她被人骂了 · 21:56】
来自：宅（1367107068）
原因：侮辱：傻子 / 重复追问

—— 对方最近说的 ——
· reset
· ?
· sid
· 你是傻子
```

现在：

```
宅在骂我。
我没再回他。

「你是傻子吗？」
「我让你回答」
「你是傻子」

要我以后都不理他吗。
回「断」我就不回了，回「留」就当没这回事。
……12 小时内你不说话，我自己会松口。

宅 · 1367107068 · 22:05
```

改动的地方：

- 分类词（侮辱 / 邀战 / 重复追问）翻成一句人话：「宅在骂我。」「宅要我跟他对骂。」
- 原文只挑**命中了攻击词**的几句，并且去掉紧挨着的重复。
  「reset」「？」「sid」这类试探不再混进正文——那不是她受的委屈。
- 结尾给的是「回断 / 回留」，不是 `/断联 1367107068` 这种指令串。
  号码缩到落款那一行。

刷屏那一路用同一套句式，只是第二行换成节奏：

```
3088186803 在刷屏。
27 秒里，10 条。
我没再回他。

「在吗」

要我以后都不理他吗。
回「断」我就不回了，回「留」就当没这回事。
……12 小时内你不说话，我自己会松口。

陌生人 · 3088186803 · 13:02
```

其余几条：

```
/断联  →  断了。
          1367107068 不会再出现在我这里。

/恢复  →  好。
          1367107068 的消息我又会看了。

/静默  →  好。我先不理他了。

/联系状态 →  断了的：1234
             不说话的：没有

             我的线是 4 分。他们到线，我就不出声。
             刷屏我也拦：60 秒里 10 条以上、每两条隔不到 4 秒。
             12 小时后我自己会松口。
```
